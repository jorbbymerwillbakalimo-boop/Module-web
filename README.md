## 🎯 Objectifs pédagogiques

Ce module correspond à la **compétence RT3** du programme national BUT R&T :  
> *Créer des outils et applications informatiques pour les R&T*

Compétences développées :
- Structurer une page web avec **HTML5** (balises sémantiques, formulaires, tableaux)
- Mettre en forme avec **CSS3** (mise en page, Flexbox, responsive design)
- Reproduire une interface existante à partir d'une maquette
